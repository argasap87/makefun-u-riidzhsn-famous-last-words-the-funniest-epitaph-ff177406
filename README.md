A make.fun entry for [Famous Last Words: The Funniest Epitaph](https://make.fun/c/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406).

`main.ts` writes one epitaph of famous last words to `/output/entry.txt`:

> Relax, I'm ninety percent sure this isn't load-bearing.

The hook is misplaced DIY confidence plus a load-bearing double meaning: "Relax" opens with the casual reassurance of a do-it-yourselfer, and "ninety percent sure" is exactly the wrong amount of confidence to have while standing under something heavy — the epitaph exists because the ten percent won. No stage directions, no explanation, just the last words of someone who was almost right.

Run with Node 22: `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose the output directory).
